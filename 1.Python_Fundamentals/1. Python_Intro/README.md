# What is Python?

Python is a high-level programming language designed to be easy to read, write, and understand. It's widely used for web development, data science, automation, AI, and more.

---

## 🔑 Key Things You MUST Learn About Python

### 1. Interpreted

Python runs code line by line using an interpreter.

- You don't need to compile your code before running it
- This makes Python great for quick testing and learning

**Example:**

```python
print("Hello, World!")
```

You can run this immediately — no compilation needed!

---

### 2. Dynamically Typed

You don't declare variable types explicitly. Python decides the type at runtime.

**Example:**

```python
x = 10        # x is an integer
x = "Hello"   # now x is a string
```

This makes coding faster and simpler, especially for beginners. Python automatically handles the type based on the value you assign.

---

### 3. Indentation-Based

Python uses indentation (spaces) instead of braces `{}` to define blocks of code.

- **Correct indentation is mandatory, not optional**
- This enforces clean, readable code structure

**Example:**

```python
if x > 5:
    print("x is greater than 5")
```

⚠️ **Warning:** Wrong indentation will cause an error. Python is strict about this!

---

## 🚀 Python Installation & Setup

### Step 1: Download Python

1. Go to [python.org](https://www.python.org)
2. Download the latest version (Python 3.x recommended)
3. **Important:** During installation, check **"Add Python to PATH"**

### Step 2: Verify Installation

Open Command Prompt (Windows) or Terminal (Mac/Linux) and type:

```bash
python --version
```

If it shows a version number (e.g., `Python 3.11.5`), Python is installed correctly! 🎉

### Step 3: Write Your First Program

1. Create a file called `hello.py`:

```python
print("Hello, Python!")
```

2. Run it using:

```bash
python hello.py
```

You should see: `Hello, Python!`
